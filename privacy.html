개인정보처리방침

시행일: 2026-11-22

  1. tsbackup은 운영자 본인이 본인의 Google Drive에 파일을 백업하기 위해 만든 개인용 도구이며, 다른 사용자에게 제공하지 않습니다.
  2. tsbackup이 Google 계정을 통해 접근하는 정보는 운영자 본인의 Google Drive 파일뿐이며, 백업 파일을 올리고 확인하는 용도로만 사용합니다.
  3. Google 사용자 데이터를 제3자에게 판매·공유·전송하지 않으며, 광고나 분석 목적으로 사용하지 않습니다.
  4. 인증 토큰은 운영자 본인의 PC에만 저장되며, 운영자는 언제든 Google 계정 설정(보안 → 타사 액세스)에서 권한을 취소할 수 있습니다.
  5. tsbackup의 Google API 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

Privacy Policy

Effective date: 2026-11-22

  1. tsbackup is a personal tool used only by its owner to back up files to the owner's own Google Drive. It is not offered to other users.
  2. The only Google user data accessed is the owner's own Google Drive files, used solely to upload and verify backups.
  3. Google user data is never sold, shared, or transferred to third parties, and is not used for advertising or analytics.
  4. Authorization tokens are stored only on the owner's PC; access can be revoked at any time in Google Account settings.
  5. tsbackup's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
